{# ========================================================================== COVERAGE REQUIREMENTS DISCOVERY (CRD) TRIGGER ========================================================================== This section contains the CRD trigger button and the panel where the payer's CDS Cards response will be displayed after the exchange completes. HOW HTMX WORKS HERE -------------------- HTMX is loaded in base.html. It reads special hx-* attributes on HTML elements and uses them to make HTTP requests without a full page reload. The button below carries three key HTMX attributes: hx-post="/orders/colonoscopy/crd" Tells HTMX to send an HTTP POST to this URL when the button is clicked. The route handler (trigger_crd in clinician.py) assembles the FHIR context, calls the payer, and returns an HTML fragment. hx-target="#cds-cards-panel" The CSS selector of the element where HTMX will insert the response. The # prefix means "find the element with id='cds-cards-panel'". hx-swap="innerHTML" Tells HTMX to replace the *inner* HTML of the target element with the response body. The target div itself stays in the DOM; only its contents are replaced. LOADING INDICATOR ------------------ hx-indicator="#crd-spinner" points to a separate element that HTMX shows while the request is in flight and hides otherwise. HTMX controls this by toggling the element's opacity — it looks for the CSS class htmx-indicator on the pointed-to element and sets opacity to 0 by default, then 1 during the request. No JavaScript is needed to wire this up. ========================================================================== #}
