{# ------------------------------------------------------------------------- base.html — Layout shell ------------------------------------------------------------------------- Every full-page template in this project extends this file. HOW TEMPLATE INHERITANCE WORKS IN JINJA2 ----------------------------------------- A child template starts with {% extends "base.html" %} and then declares one or more {% block %} ... {% endblock %} sections. Jinja2 merges the child's blocks into this shell at render time. Blocks defined here but not overridden by the child use the default content written here.
